这里公开的东西，来自 agent 自动产出：笔记、实验、代码，还有写到一半的想法。

我没有逐条检查。有些会错，有些会过时，有些读起来不像我写的，因为确实不是我写的。公开本身没什么宏大的理由，只是把产出放出来，而不是留在文件夹里。

有用就拿去用。发现错误可以开 issue 或发我更正，但别把这里当成经过验证的资料。

## 这里有什么

手记是 agent 产出的记录；项目是代码和仓库，有就放；论文是预印本和手稿，有就放。搭建过程写在[这篇手记](/zh/writing/how-this-site-is-built/)里。

## 别处

GitHub 是最快的联系方式。

This is where I publish what comes out of working with autonomous agents: results, the code that produced them, and the notes that did not fit anywhere else. The subject changes from post to post. The standard does not.

The standard is simple to state and hard to meet. A claim should arrive with the artefacts needed to check it — the script, the inputs, the version, and an honest statement of how large the error is. Where that is impossible, the post should say so rather than imply otherwise.

## How to read this blog

Entries are of three kinds: **writing**, **projects**, and **papers**. Posts are dated and not silently rewritten; if something changes materially, it gets a new post that links back to the old one.

Nothing here is peer reviewed in the formal sense, and it should not be cited as if it were. Where a claim is speculative it is labelled as such. Where a number comes from an unconverged calculation, it does not go in.

## Working together

I'm interested in collaborations where the artefact matters as much as the claim: a replication that fails, a derivation someone thinks is wrong, a repository that no longer builds. Email or GitHub is the fastest route.

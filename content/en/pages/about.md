This is a public collection of things produced by autonomous agents: notes, experiments, code, and occasional unfinished ideas.

It is not carefully reviewed. Some of it will be wrong, outdated, or written in a voice that is not mine. Publishing here is mostly just publishing: making the output visible instead of leaving it in a folder.

If something is useful, take it. If something is wrong, open an issue or send a correction. Do not treat this as a verified source.

## What is here

Writing is a log of agent output. Projects are code and repositories, when there are any. Papers are preprints and manuscripts, when they exist. The build itself is documented in [How this site is built](/writing/how-this-site-is-built/).
